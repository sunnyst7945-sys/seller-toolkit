# 🛠️ 电商运营工具箱 (Amazon Seller Toolkit)

一站式电商运营小工具，纯前端实现，无需后端，可部署到 GitHub Pages 永久使用。

## 功能模块

| 模块 | 说明 |
|------|------|
| 📐 单位换算 | 长度/重量/体积/面积/温度 五类并列，每类 4 组输入框（可同时算长宽高等），任意单位框输入即联动换算同组其余单位 |
| 💱 货币换算 | 每日实时汇率（自动更新，缓存 24h），24 个币种输入框联动，输入一个同步换算所有 |
| 🏷️ Made in China | 一键为 PDF / JPG / PNG 添加「Made in China」产地标识，支持批量、ZIP 打包下载，全程本地处理 |
| 📦 HS 编码查询 | 10 位中国海关编码（前 6 位国际 + 7-8 位税则 + 9-10 位附加码），支持中英文关键词检索、可跳转权威网核对 |
| ✂️ 标题拆分 | 流水线式拆分：先拆 75 字符标题，剩余自动进 125 字符亮点（保持语序），支持多行批量 |
| 🔠 大小写转换 | 全部大写 / 全部小写 / 首字母大写 / 句首大写，结果合并输出、一键复制 |

## 技术说明

- 纯前端（HTML + CSS + 原生 JS），无框架依赖
- 汇率数据源：`open.er-api.com`（主）→ `frankfurter.app`（备），每日自动更新
- PDF 处理依赖 `pdf-lib`，ZIP 打包依赖 `JSZip`（均通过 CDN 加载）
- 所有文件处理均在浏览器本地完成，不上传服务器

## 文件结构

```
index.html   主页面（结构 + 样式）
app.js       交互逻辑
logic.js     核心纯函数（单位/货币/大小写/标题/HS 查询）
data.js      HS 编码数据库
test.js      Node 单元测试
```

## 本地运行

```bash
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

## 测试

```bash
node test.js
```

## 免责声明

- 汇率仅供参考，实际成交以银行/支付渠道为准
- HS 编码前 6 位为国际通用编码、第 7-8 位为中国税则号，第 9-10 位附加码无特殊监管的商品为 00；实际申报请以中国海关最新《进出口税则》为准，可在 [海关编码查询网](https://www.hsbianma.com/) 二次核对
